# Proposed Prisma Enums

Stable enums belong in the proposed schema; configurable business categories remain tables.

```prisma
enum PartyKind { PERSON ORGANIZATION }
enum BranchAccessMode { BRANCH MULTI_BRANCH COMPANY_WIDE }
enum ServiceModel { BROKERAGE TENANT_PLACEMENT FULL_MANAGEMENT MASTER_LEASE_SUBLEASE RENT_COLLECTION_ONLY COMPANY_OWNED }
enum EngagementStatus { DRAFT REVIEW APPROVED ACTIVE SUSPENDED TERMINATING ENDED REJECTED CANCELLED }
enum LeaseKind { STANDARD SUBLEASE COMPANY_OWNED COLLECTION_ONLY }
enum LeaseStatus { DRAFT REVIEW APPROVED SIGNING SIGNED PENDING_POSSESSION ACTIVE NOTICE HOLDOVER ENDED CANCELLED }
enum ReservationStatus { PENDING ACTIVE CONVERTED EXPIRED CANCELLED RELEASED }
enum PaymentStatus { CAPTURED VERIFYING VERIFIED POSTED PARTIALLY_ALLOCATED FULLY_ALLOCATED REJECTED REVERSED }
enum JournalStatus { DRAFT POSTED REVERSED }
enum PeriodStatus { OPEN SOFT_CLOSED CLOSED LOCKED }
enum FundClass { COMPANY_FUNDS OWNER_FUNDS SECURITY_DEPOSIT_FUNDS TENANT_CREDIT_FUNDS }
enum DepositTxnType { RECEIPT ADJUSTMENT DEDUCTION TRANSFER REFUND REVERSAL }
enum ApprovalStatus { REQUESTED PENDING APPROVED REJECTED EXPIRED WITHDRAWN }
enum PayoutStatus { DRAFT REVIEW APPROVED QUEUED PROCESSING PAID RECONCILED HELD REJECTED FAILED CANCELLED }
enum UtilityAllocationMethod { EQUAL AREA_BASED METERED OCCUPANCY_BASED FIXED_AMOUNT CUSTOM_PERCENTAGE }
enum OccupancyMode { EXCLUSIVE SHARED }
```

`SHARED` is reserved and cannot be used in MVP without the Phase 2 shared-occupancy aggregate and constraints.
