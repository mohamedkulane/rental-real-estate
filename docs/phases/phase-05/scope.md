# Phase 5 Scope and Sub-phase Gate

Phase 5 is delivered through separately approved sub-phases. This repository change implements **only Phase 5.1 Service Engagements & Capability Resolver**.

## Included in 5.1

- effective-dated Service Engagement aggregate and lifecycle history;
- seven approved Service Models and deny-by-default compatibility matrix;
- Property inheritance and RentableSpace override policy;
- centralized capability resolver;
- database constraints, serialization, company ownership proof, permissions, audit, numbering, and seed;
- focused Service Engagement register, detail workspace, lifecycle actions, server-side filters, cursor pagination, stable ordering, and accurate matching total;
- automated and responsive UI validation.

## Explicitly excluded

CRM, Contacts, Leads, Listings, Viewings, Applications, Reservations, Leases, Billing, Deposits, Maintenance, Owner Statements, and Owner Payouts are not started. Those belong to Phase 5.2 or later and require separate approval.
