# Phase 2 Scope

## Included

- pnpm workspace with web, API, database, shared, and configuration packages
- Next.js App Router shell with Tailwind-compatible styling and validated web configuration
- NestJS REST shell with URI versioning, validation, CORS, correlation IDs, structured logging, opt-in non-production Swagger, and consistent error envelopes
- Prisma client generation for the approved operational schema
- PostgreSQL, Redis, and BullMQ development infrastructure
- unit, integration, end-to-end, lint, formatting, typecheck, build, and CI controls

## Excluded

Phase 3 identity/business access and Phase 4 portfolio behavior were not part of the Phase 2 implementation. Phase 5 and later business modules remain excluded.
