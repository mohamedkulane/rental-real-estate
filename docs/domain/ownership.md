# Property Ownership

Property ownership connects an Owner Party to a Property through effective-dated Decimal percentage history. Payout entitlement is an independent effective-dated Decimal history attached to the ownership record; unequal ownership and payout shares are supported when both totals remain valid.

Replacement closes current intervals and inserts a new configuration in one transaction. Overlap exclusions and uniqueness constraints reject ambiguous history. Draft Properties may temporarily have incomplete configuration. Active Properties require ownership and payout totals of exactly 100%, active owner profiles, and a valid operating branch for every effective segment.
