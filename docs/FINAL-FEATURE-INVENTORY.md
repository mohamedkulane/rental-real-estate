# Final Feature Inventory

Present and retained: company and branch access, RBAC, effective branch scope, owners, properties, buildings, rentable spaces, amenities, protected documents and versions, rental brokerage, full management, customers, buyers, viewings, selected-unit workflow, agreements, leases, move-in/out, renewals, payments and allocation, reversals, expenses, statements, maker-checker payouts, sales settlement, maintenance, work orders, inspections, defects, vendors, notifications, reports, CSV/XLSX export, fuzzy property search, dashboard read models, Start New, and Development.

Development is intentionally independent and supports projects, blocks, plots, budgets, costs, and conversion to canonical sale-ready properties. The retired Construction product domain is not part of the active schema, API, navigation, seed, reports, permissions, or tests. Historical migrations remain only as append-only database history.

Final product-experience capabilities include generated Lease, Sale Agreement,
Payment Receipt, and Owner Statement PDFs; permission-aware command palette
navigation; one PostgreSQL-backed fuzzy global search; idempotent operational
notifications; user-owned Saved Views; bounded per-resource follow-up bulk
completion; user-facing activity timelines; and lightweight WhatsApp deep
links for authorized unmasked owner/customer/buyer contact values.
